# Türkiye Meshtastic Topluluğu'nun Resmi İnternet Sitesi

> Bu repo, TA Mesh internet sitesinin kaynak kodlarını barındırmaktadır.

## TA Mesh Nedir?
Purgatoria Topluluğu'nun bir alt topluluğu olan Meshtastic Türkiye Topluluğu veya TA Mesh, ülkemizde Meshtastic projesini yaygınlaştırarak muteber bir altyapı kurmayı ve bu süreçte mensuplarına RF'in temel konularını öğretmeyi amaç edinen, kâr amacı gütmeyen bir topluluktur.

## Geliştirmeye Katkıda Bulunma (Pull Request)
1. Bu repoyu kendi GitHub hesabınıza çatallayın (Fork).
2. Kendi modülünüzü .js dosyası olarak ekleyin.
3. Kendi reponuza commit edip pushlayın.
4. Bu repoya bir Pull Request (PR) açın.
5. PR'ınız onaylandığında, ana sunucu güncellenecek ve modülünüz ağda aktif olacaktır!

## Nelerle Katkı Sağlayabilirsiniz?
1. Teknik rehberler, güncel haberler ve Meshtastic ile ilgili blog yazıları.
2. Web sitesinin kullanıcı deneyimini (UX) zenginleştirebilecek ve basitleştirebilecek arayüz çalışmaları.
3. Web sitesi altyapısını optimize edecek özellikler.
4. Topluluğun işine yarayacak yeni fonksiyonlar.

## Hata Bildirimi:
Web sitesinde karşılaştığınız sorunları Issues sekmesi üzerinden bildirebilirsiniz.
Veya WhatsApp grubundan da yazabilirsiniz sevgili dostlar.
